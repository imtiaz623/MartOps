Backup and reports

MartOps kya kar sakta hai

  • Automatic record: manager ka phone branch ke Wi-Fi se judta hai to arrival aur jaane ka time khud save hota hai. Koi button nahi.
  • Unlimited branches aur Wi-Fi: har branch ke jitne chahe Wi-Fi names.
  • Live status: At branch, Other Wi-Fi, Mobile data, No internet, Phone off, aur Company time ke baad Off duty.
  • Out-of-range report: kab branch se gaya, kis wajah se, wapas kab aaya aur kitni der.
  • Download: Excel, PDF, Text aur Image, kisi bhi date range ki.
  • Company time: sirf aap ke set kiye hue time mein record, uske baad manager ki koi tracking nahi.
  • App band ya phone restart: tracking khud chalti rehti hai, internet na ho to baad mein sync.
  • Location: company time mein har 5 minute mein manager ki GPS location (Google Maps link ke saath). Company time ke baad kuch record nahi.
  • Backup: chaho to visits aap ki apni Google Sheet mein bhi aati hain.

Step-by-step Guide

Owner (web panel)

  1. Branch aur Wi-Fi: "Branches and Wi-Fi" tab kholo. Branch ka naam, location ka naam aur us branch ke Wi-Fi ke naam likho. Wi-Fi ka naam bilkul waise likho jaise phone ki Wi-Fi list mein dikhta hai. Ek branch ke kai Wi-Fi ho sakte hain ("+ Add another Wi-Fi").
  2. Company time: Settings mein start aur end time aur din chuno, phir Save. Sirf isi time mein record hota hai. Time set na karo to poora din record hoga.
  3. Manager add karo: "Managers" tab mein naam likho. Manager ID aur PIN sirf ek baar dikhti hai, usay manager ko de do.
  4. Manager ka phone: app install karke Company code, Manager ID aur PIN se login karwao (neeche dekho).
  5. Unlock PIN (zaroori nahi): Settings mein PIN set karo, phir manager PIN ke baghair logout nahi kar sakta.
  6. Report: "Reports" tab mein date chuno aur Excel, PDF, Text ya Image download karo.

Manager (Android app)

  1. App kholo, Login dabao, Company code, Manager ID aur PIN likho.
  2. Jo notice aaye usay padh kar Agree dabao.
  3. Location permission mein "Allow all the time" aur "Use precise location" chuno.
  4. Phone ki Location (GPS) on rakho.
  5. Notifications allow karo (tracking ka notification dikhta rahega).
  6. Settings > Apps > MartOps mein Battery = Unrestricted aur Autostart = ON karo.
  7. Bas. Ab app khud chalti hai, app band ho ya phone restart ho.

Masle ka hal

  • Wi-Fi ka naam nahi mil raha: phone ki Location (GPS) on karo aur "Allow all the time" chuno.
  • Branch par hai magar "Other Wi-Fi" dikha raha hai: Wi-Fi ka naam branch mein galat likha hai. Edit karke theek karo.
  • "No signal": phone band hai, internet nahi hai ya app ko battery ne rok diya. Battery ko Unrestricted karo.
